Fusion Pipeline
1. Position fusion — MAVLink GPS + radar xyz + LiDAR xyz → lat/lon via sensor mast transform
2. 3D Geo-fence — polygon + altitude band check at 5 Hz on both MAVLink and sensor positions
3. Camera confirm — YOLO detection validates radar/LiDAR when target in FoV
4. MMAUD classify — radar + avia + mid360 class probabilities → weighted average fusion
5. Audio flag — acoustic signature raises secondary detection flag
6. Threat assessment — max(MAVLink geofence, sensor geofence) → fused threat level
⚠ Current fusion = simple average. Kalman filter track-level fusion planned for v2.
